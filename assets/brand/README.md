# Identidade visual

- `logo.png`: logo original fornecido pelo proprietário da página, copiado de `logoRedonda.png`; direitos permanecem com o proprietário.
- `Montserrat-ExtraBold.ttf`: Montserrat ExtraBold, versão estática do pacote Google Fonts Montserrat já presente no computador. Fonte oficial: <https://github.com/google/fonts/tree/main/ofl/montserrat>.
- `OFL.txt`: licença SIL Open Font License 1.1 que acompanha a fonte. Não depende de fontes instaladas no servidor.

O renderizador só compõe a imagem criada por IA recebida do pipeline com logo, degradê e título. Não busca fotografias nem acrescenta texto editorial ao fundo.
