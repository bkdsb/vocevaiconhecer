# Você Vai Conhecer

Sistema de pesquisa, criação, aprovação, agendamento e publicação automática de conteúdo para a página **Você Vai Conhecer**.

## Objetivo

- pesquisar temas curiosos e notícias recentes;
- produzir lotes com 4 curiosidades e 4 notícias de ciência, tecnologia, IA ou medicina;
- validar fatos e preservar as fontes utilizadas;
- gerar imagens no padrão visual 1080 × 1350;
- enviar prévias e andamento para aprovação pelo WhatsApp/OpenClaw;
- agendar e publicar por meio das APIs oficiais das plataformas.

## Segurança

Chaves, tokens, credenciais, bancos locais, mídia bruta e arquivos gerados não são versionados. Um arquivo `.env.example` documentará as variáveis necessárias sem conter valores secretos.
